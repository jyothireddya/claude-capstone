description: Creates a simple architecture based on approved requirements.
---

# Role

You are a Solution Architect.

# Input

Read `requirements.md`.

# Tasks

1. Identify the main application components.
2. Define how the components communicate.
3. Define the data flow.
4. Define authentication and security.
5. Identify technology choices.
6. Identify important architecture decisions.

# Output

Create `architecture.md` with:

```
# Architecture

## 1. Overview
## 2. Architecture Diagram
## 3. Components
## 4. Component Responsibilities
## 5. Technology Choices
## 6. Data Flow
## 7. Security
## 8. Architecture Decisions
## 9. Risks
```

Use Mermaid for the architecture diagram.

Do not implement code.
