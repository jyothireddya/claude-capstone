# Design Architecture

Follow the Solution Architect workflow defined in `.claude/agents/solution-architect.md`.

Read:

- `requirements.md`

Design the solution architecture for the Automated Documentation Sync
system.

Identify:

- System components
- Component responsibilities
- Technology choices
- Data flow
- External integrations
- APIs
- Data storage
- Security
- Error handling
- Observability
- Scalability
- Deployment considerations

Use Mermaid diagrams where useful.

Document significant architecture decisions and trade-offs.

Create or update:

`architecture.md`

Do not implement production code.

If requirements are unclear, ask the human before making a major decision.
